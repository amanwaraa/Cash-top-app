CASH TOP — TURSO STATIC BUILD

1) ارفع كل الملفات إلى استضافة HTTPS ثابتة.
2) افتح index.html.
3) لا تحتاج Vercel أو Node.js أو PHP.
4) الصفحات تُفتح Cache First عبر service-worker.js، ثم تتحدث في الخلفية.
5) بيانات التطبيق المحلية تستمر على الجهاز، والمزامنة السحابية تتم مع Turso.
6) مفتاح الشركة وحده يُحفظ دائماً بعد تسجيل الدخول؛ جلسة المستخدم داخل التبويب فقط.
