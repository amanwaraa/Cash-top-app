# CASH TOP — Turso R74

هذه النسخة تعمل كتطبيق ويب ثابت على Turso بدون MongoDB أو Vercel أو Firebase Backend.

## الكاش وفتح الصفحات

- كل صفحات التطبيق المحلية محفوظة مسبقاً في **Cache Storage**.
- التنقل **Cache First** دائماً: الصفحة المحفوظة تُعرض فوراً حتى عند توفر الإنترنت، ثم يُحدَّث ملف الصفحة في الخلفية على فترات متباعدة.
- بيانات العمل المحلية تبقى متاحة فوراً من تخزين الشركة المحلي، ولا ينتظر فتح الصفحة تنزيل قاعدة البيانات.

## المزامنة الاقتصادية وشبه اللحظية

- إذا دخل المستخدم صفحة وهناك عمليات محلية غير متزامنة، يبدأ رفعها مباشرة في الخلفية.
- أثناء بقاء الصفحة ظاهرة يتم فحص **صف meta واحد فقط تقريباً كل 15 ثانية** لاكتشاف تعديلات جهاز آخر.
- يحتوي meta على طوابع تغيير لكل dataset؛ عند اكتشاف تغيير لا يتم تنزيل بيانات الشركة كلها، بل **الـ datasets المتغيرة والمطلوبة للصفحة الحالية فقط**.
- الصفحات المخفية لا تستمر في الفحص الدوري.
- الحفظ المحلي يظهر فوراً، والكتابات إلى Turso تبقى مجمعة/مؤجلة قليلاً لتقليل عدد عمليات الكتابة.
- لا يوجد Read-after-write للتحقق بعد كل حفظ، ولا Full Pull بعد كل تعديل.
- هذه مزامنة شبه لحظية اقتصادية وليست Push حقيقياً؛ لذلك يوجد فحص meta خفيف ما دام التطبيق مفتوحاً.

## الاستيراد

- يمكن استيراد نسخة كاملة أو نسخة قسم حتى لو كانت صادرة من **مفتاح شركة مختلف**.
- هوية المفتاح الحالي، الاشتراك والمدير الحالي لا يتم استبدالهم بهوية النسخة المستوردة.
- الأقسام المطابقة محلياً لا تُرفع مرة أخرى.
- الأقسام المتغيرة فقط تُرفع إلى Turso بدفعات UPSERT.
- لا توجد قراءة تحقق بعد كل كتابة ولا تنزيل كامل بعد الاستيراد.
- عند انقطاع الإنترنت تبقى التعديلات محلياً وتُرفع عند عودة الاتصال.

## الإشعارات

- تمت إعادة **قسم الإشعارات** وإشعارات المدير الذكية مثل المخزون المنخفض والاستحقاقات والتنبيهات التشغيلية.
- تم تعطيل **إشعار المدير الناتج عن إنشاء فاتورة مبيعات جديدة فقط**.

## تسجيل الدخول على الجوال واللابتوب

- بعد نجاح الدخول يتم تذكر **مفتاح الشركة فقط** بشكل دائم.
- بيانات جلسة المستخدم تبقى داخل التبويب؛ أضيف fallback عبر `window.name` لتجاوز مشاكل بعض متصفحات اللابتوب/أوضاع الخصوصية التي تعطل انتقال `sessionStorage` أثناء فتح لوحة التحكم.
- عند تسجيل الخروج يتم مسح جلسة التبويب، بينما يمكن إبقاء مفتاح الشركة لتسهيل الدخول القادم.

## الخطط

يوجد الآن: **Plus / Pro / مخصصة**.

الخطة المخصصة تسمح للمشرف العام بتحديد:

- حدود تتجدد يومياً: فواتير المبيعات، العملاء الجدد، المصاريف، الموردون الجدد.
- حدود ثابتة: الموظفون، المخازن، الفروع، المنتجات.
- ترك أي حد فارغاً يعني غير محدود.

صفحة الإعدادات تعرض مفتاح الشركة وتفاصيل الخطة فقط ضمن بطاقة الاشتراك.

## تنبيه أمني

هذه نسخة Static Web، لذلك Turso Auth Token الموجود في ملفات JavaScript يمكن قراءته من ملفات الموقع. بعد اكتمال الاختبار يجب تدوير التوكن الذي تم مشاركته في المحادثة واستخدام توكن جديد مناسب للتشغيل الفعلي.
